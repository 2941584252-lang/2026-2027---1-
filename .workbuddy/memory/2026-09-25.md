### 本机环境踩坑
- 该环境下 Vite 构建清空 `dist` 会因回收站式安全删除失败（genie-safe-delete 报错）。绕法：先把 `dist` 改名（mv），让 Vite 新建目录。
- `gh auth setup-git` 在此环境无效（静默失败），git 推 GitHub 需用一次性 token URL：
  `git push https://x-access-token:$(gh auth token)@github.com/OWNER/REPO.git 分支:分支`
