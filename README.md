# “智汇工坊”——面向跨专业学习场景的 AI Skill 与 Agent 共创实践平台

> **项目属性**：陕西师范大学 2026-2027 学年勤工助学实践创新重点项目  
> **申报单位**：人工智能与计算机学院  
> **核心团队**：计创2502 班 崔启霖（负责人）、陈靖昊、于咏琪、董吉祥、张钥童、周佳艺  
> **技术栈**：React 18 + TypeScript + Vite + Tailwind CSS + Lucide Icons + Recharts

---

## 🌟 一、项目背景与核心定位

本项目依托陕西师范大学人工智能与计算机学院专业技术优势，组织计算机专业学生面向文、史、哲、经管、医学等跨学科学生，开展 **AI 学习工作流共创实践**。

针对当前大学生使用生成式人工智能普遍停留在“简单问答、资料检索、单次翻译”等浅层交互，缺乏与深度专业学习场景结合的痛点，项目采用：
> **“计算机专业学生提供技术支持 + 其他专业学生提供真实学习场景”** 的共创机制。

将生成式人工智能从单次对话升级为：
1. **可复用的 AI Skill**：具备明确的输入契约、处理步骤、判断规则与结构化格式。
2. **自主协同的 AI Agent**：基于学习目标自主进行任务分解、动态技能路由与多节点批判反思闭环。
3. **沉淀跨学科学习资源库**：涵盖人文社科、经管类、理工类、医学与生命科学、艺术设计五大门类的真实痛点解决方案。

## 🛠️ 三、技术架构与开源项目借鉴说明

### 1. 核心技术栈
- **UI 运行时**：React 18 + TypeScript + Vite 5
- **样式系统**：Tailwind CSS + Tailwind Animate + 深色/浅色双主题
- **矢量图标**：Lucide React
- **图表可视化**：Recharts
- **交互流程图**：自定义轻量级 SVG/Canvas 高性能流水线拓扑组件（具备脉冲波纹、节点状态下钻）

## 🔌 四、AI 引擎运行模式说明（Mock vs 真实 API）

网站开箱即用，设计了高健壮性的双引擎架构：

### 1. 默认：Mock 模拟演示模式（无需任何 API Key）
- **适用场景**：评委评审、答辩演示、本地快速体验。
- **运行特征**：系统内置了由团队经过多轮打磨的真实跨学科专业学术数据（ResNet 论文残差精读报告、操作系统 PV 操作与死锁自测题库、实证学术论文逻辑漏洞巡检报告等）。
- **演示效果**：具有真实的阶段性执行延迟模拟（逐级推进 7 步流水线与节点脉冲），完整呈现多智能体协同过程。

### 2. 真实大模型 API 模式
- **支持模型**：OpenAI (GPT-4o / GPT-4o-mini)、DeepSeek (deepseek-chat / deepseek-reasoner)、Gemini 或任何兼容 OpenAI 接口规范的聚合端点。
- **配置方式**：点击页面右上角 **齿轮设置图标** ⚙️，在弹窗中选择“真实大模型接口”，填入 API Key 与 Base URL 即可。配置仅保存在用户本地浏览器 LocalStorage，安全无泄露风险。

## 💻 五、本地启动与构建运行指南

### 1. 环境准备
- Node.js >= 18.0.0 (推荐 Node 20 / 22)
- npm >= 9.0.0

### 2. 安装依赖
```bash
npm install
```

### 3. 本地启动开发服务器
```bash
npm run dev
```
启动后在浏览器中访问：`http://localhost:5173` 即可进入系统。

### 4. 生产环境构建打包
```bash
npm run build
```
编译产物将输出至 `dist/` 目录，确保 TypeScript 类型检查 0 报错。

### 5. 生产构建本地预览
```bash
npm run preview
```
